# Vitality Plan

Build a modern AI powered weight loss web application with a clean, modern, mobile-first UI. The app should help users lose weight through personalized nutrition planning. Features: user onboarding with age, gender, height, weight,

target weight, activity level, dietary preferences, allergies, and daily routine. Calculate BMI, estimated body fat, BMR, TDEE, and a safe calorie deficit. Generate a personalized seven-day meal plan with breakfast, lunch, dinner, and snacks. Generate a smart shopping list based on the meal plan. Allow users to regenerate individual meals. Show daily calories, protein, carbohydrates, fats, and fiber. Track weight progress with charts and weekly goals. Save user progress with authentication. Include light and dark mode. Add a beautiful dashboard with modern cards, charts, and smooth animations. Add a premium subscription with Free and Pro plans. Make the design feel premium, similar to Apple or Stripe. Make the application fully responsive, for desktop and mobile. Use a modern tech stack, and prepare the project for AI integration through an API.
